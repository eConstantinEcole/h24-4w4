**Auteur: Constantin Schmouker** 
**Titre: Club de Voyage**
## Description: ##

**Projet Scolaire - Développement d'une Page Web sur un Club de Voyage (Cours 4W4)**  

Dans le cadre du cours 4W4, notre projet consiste à concevoir et développer une page web dédiée à un club de voyage. L'objectif est de créer une plateforme interactive et attrayante qui présente les destinations, les activités proposées et les avantages d'adhérer au club. Le site devra inclure une interface utilisateur ergonomique, une mise en page responsive et des fonctionnalités dynamiques comme un formulaire d'inscription ou une section de témoignages. Ce projet nous permet d'appliquer nos connaissances en HTML, CSS et JavaScript tout en développant des compétences en conception web et en expérience utilisateur.
